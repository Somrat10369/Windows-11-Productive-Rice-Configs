# Setup Guides

This repository is a collection of Windows configurations, not a one-click installer. You do not need to install everything to get value from it. These guides give you a practical route from a small visual refresh to a fully customized productivity environment.

## Choose your path

| Guide | Best for | Estimated time | Difficulty |
|---|---|---:|---|
| [Beginner](beginner.md) | New to Windows ricing; prefers graphical setup and no code | 40–55 minutes | Easy |
| [Intermediate](intermediate.md) | Comfortable following configuration instructions and editing simple settings | 2–3 hours | Moderate |
| [Advanced](advanced.md) | Experienced users who want to integrate and customize the wider setup | 4–6+ hours | Advanced |

**Time estimates are initial planning estimates, not verified guarantees.** They exclude downloads that take unusually long and time spent personalizing every detail. They should be tested with someone unfamiliar with the repository and adjusted based on that experience.

## How to use these guides

- Follow one step at a time and confirm it works before moving on.
- Back up existing settings before replacing configuration files.
- Check each component's own README for exact installation steps, dependencies, configuration paths, and keybindings.
- Treat optional steps as optional. You can use components independently.
- If something breaks, undo the last change before making more changes.

### Labels

- **Required:** needed to complete that guide's main path.
- **Optional:** useful, but safe to skip.
- **Advanced:** requires more familiarity with configuration or troubleshooting.
- **Caution:** may change system behavior, replace settings, or require elevated permissions.

## Before you start

1. Confirm you are using Windows 11 and read any prerequisites listed by the component.
2. Back up the configuration you are about to change.
3. Download tools from their official sources and review scripts before running them.
4. Do not disable security features or run commands as administrator unless the instructions and trusted source justify it.
5. Remember that screenshots and paths may differ across Windows versions and display setups.
