## Introduciton

File Pilot is a lightweight, high-performance Windows file manager currently in beta that serves as a modern alternative to the native File Explorer.  Engineered from scratch in C with a custom renderer, it prioritizes blazing speed and responsiveness, loading directories and executing commands almost instantaneously with a standalone executable size of under 2 MB.

![FilePilot](../Assets/File_Pilot.png)

## Installation

* Download the exe form the [Officail Website](https://filepilot.tech)

## Setup

* Goto the default config location `C:\Users\<YourUsername>\AppData\Roaming\Voidstar\FilePilot\` and paste/replace the [config](FPilot-Config.json) there
